# E-Commerce Data Engineering Platform

## Overview

An end-to-end data engineering portfolio project that
processes e-commerce data to support reliable analytics
and late-delivery prediction.

## Objectives

- Build ETL and ELT pipelines.
- Organize data into Bronze, Silver, and Gold layers.
- Implement data quality checks.
- Orchestrate workflows with Apache Airflow.
- Transform warehouse data using dbt.
- Track machine learning experiments with MLflow.
- Automate testing and image builds using CI/CD.
- Containerize applications with Docker.
- Deploy services locally with Kubernetes.
- Monitor pipelines and services.

## Technology Stack

Python, PostgreSQL, MinIO, Apache Airflow, dbt,
Docker, Kubernetes, Git, GitHub Actions, MLflow,
Apache Kafka, Prometheus, and Grafana.

## Dataset

Brazilian E-Commerce Public Dataset by Olist:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
